# Betweenly 本地试用

## 启动与关闭

1. 安装 Node.js 22.18 或更高、.NET 8 SDK 和 Python 3.11 或更高，首次运行在 frontend 目录执行 `npm ci`。
2. 在 Windows 双击项目根目录 `Start-Betweenly.cmd`，等待显示 `MVP_READY`，打开 http://127.0.0.1:3000。
3. 使用结束后在启动窗口按 Ctrl+C；后台实例也可通过 `scripts/stop-mvp.ps1` 停止。停止不会删除本地数据。

首次会构建后端和网关。若项目内已有 `.runtime/dotnet-sdk/`，启动器优先使用该 SDK，不修改系统 PATH。Python 可通过 `BETWEENLY_PYTHON` 指定。

此启动器是仅在回环地址运行的开发试用入口：显式启用 `VITE_LOCAL_MVP=1` 和对应的 5080 Gateway 代理，不要求 MySQL 账号服务。常规账号网页版与生产构建继续要求登录，Electron 另用本地桌面身份；不要将开发试用入口暴露到公网。

## 使用

1. 设置 → 连接设置，填写自己的 DeepSeek API Key。Jev 可选，填写后启用独立复核；Windows 上密钥由当前系统账户 DPAPI 加密保存。
2. 新建联系人，添加聊天/图片记录，或通过批量粘贴导入并核对说话人。网页端不读取本机微信，微信助手只用于桌面版。
3. 勾选需要分析的记录，选择目标，填写具体问题与可选草稿，点击“查看建议”。
4. 核对建议和依据，编辑后复制；项目不会自动发送消息。
5. 设置 → **个人语料库**，粘贴自己的真实表达或读取 UTF-8 TXT。聊天文本可选择自己的昵称，核对预览并确认后批量导入。
6. 生成时自动参考相关语料；回复框的 **存为我的表达** 可保存你确认后的修改。“表达习惯”页可独立暂停语料参考。详见 [个人语料库](PERSONAL_VOICE.md)。

未配置有效模型密钥时，记录和语料管理可使用，生成会返回配置错误。模型名称或额度不可用时，可在私有 `.env` 配置 `DEEPSEEK_MODEL` 并重启；默认使用仓库当前模型配置。

## 本地文件

- 服务日志：`.runtime/mvp/logs/`。
- 明文背景及个人语料：`.runtime/mvp/data/`，请注意电脑和备份权限。
- 加密模型凭证：上述目录下 `model-credentials/`。安装版数据独立位于当前 Windows 用户的 `%APPDATA%/Betweenly/`，不自动迁移。
- `.env`、`.runtime/`、截图及依赖均被 Git 忽略，不应提交聊天、语料或密钥。
