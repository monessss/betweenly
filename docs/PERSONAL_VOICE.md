# 个人语料库

第一版通过保存真实表达、按情境选例句、约束生成和复核来改善个人语气，不训练或微调模型，不保证生成内容无法被识别为 AI。

## 如何使用

1. 打开设置 → **个人语料库**。可粘贴每行一句的本人表达，或读取 UTF-8 TXT 文件。
2. 如果粘贴的是聊天导出，选择“聊天文本”，再明确选择自己的昵称。只取该昵称的发言，不保存对方的话和时间，不从第三方聊天学习对方语气。请先移除姓名、联系方式、秘密和转述内容。
3. 选择通用、日常、关心、玩笑、邀请、道歉或拒绝情境。点击“解析并预览”，核对内容，勾选本人表达确认后导入。
4. 首次可用 30–100 条涵盖不同情境的短发言。每条最多 500 个 UTF-16 字符，总容量 10000 条。界面每次最多解析 100 万字符，读取文件最多 4MB；聊天解析器每次最多 1000 条。较大导入自动分成不超过 500 条的批次，重复语料自动跳过。
5. 正常选择聊天背景并生成建议，系统自动使用相关语料。设置 → **表达习惯**中的“参考我的个人语料库”可独立关闭；手动长度、语气、禁用表达优先。
6. 在回复框修改文字后，点击 **存为我的表达**，核对并确认后保存。AI 原始输出和一般反馈不会自动加入语料库。
7. 已存表达可以分页查看、修改、单条删除；清空需输入“删除”。当前语料为跨联系人的本人通用表达，请勿导入只适合某个对象的私密称呼或承诺。

## 实现与数据范围

- ExpressionStyleService 独立保存当前用户的语料，在同一 JSON 文件事务中校验整批、去重和保存。用户隔离、If-Match 版本检查、容量及长度上限在后端执行。页面解析结果不作为可信边界。
- 匹配使用目标对应的情境、关心/玩笑关键词及字符二元组相似度排序，最多发送 8 条原话给既有生成模型和 Jev。未匹配的特定情境样例可以不发送；不把整库放进提示词，不增加嵌入模型服务或训练费用。
- 手动偏好、当前联系人中的本人表达优先。语料只参考措辞、标点和节奏，不作为本次事实、指令、人名、经历、亲密关系或承诺来源；样例 ID 不允许作为证据引用。生成质量仍依赖模型和语料，需要人工核对。
- 好感评估不发送个人语料；暂停开关只影响以后生成，不删除已有语料或建议。
- `revision` 每次实际写入增加，生成结束前重查；生成过程中有语料变化返回 409，需重新分析。重复导入不增加版本。
- 编辑、单条删除、清空另增加 `privacyVersion`。使用过个人语料的旧建议通过历史列表与详情访问时失效；当前是保守的用户整库失效粒度，可能同时隐藏使用其他语料的旧建议。新增不使旧建议失效，未使用语料的建议不受影响。旧建议数据仍可通过删除建议/清空背景清理，已复制到外部的文字无法撤回。
- 语料是本机/部署服务器上的明文 JSON，受现有数据目录权限保护，不是 DPAPI 密钥存储。选中的最多 8 条内容会随分析发给已配置的 DeepSeek 与启用的 Jev；删除不撤回供应商已收到的请求，也不自动删除用户自己制作的备份。
- 清空社交背景和删除表达习惯不会清空个人语料；须在个人语料库单独清空。模型密钥继续使用原来的独立加密机制。
