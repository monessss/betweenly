# Betweenly（之间）

一个面向真实社交情境的行动与表达助手。它帮助用户整理背景、判断当前更合适的下一步，并生成符合本人语气、尊重双方边界的表达建议。

> 当前状态：产品与协议基线。尚未接入模型、前端、数据库或部署环境。

## 核心原则

- 先解决“现在可以做什么”，再给可直接使用的表达。
- 建议必须引用具体消息、事件或用户说明作为依据。
- 明确区分事实、用户转述、观察和待确认的推测。
- 信息不足时承认未知并只追问会改变建议的关键问题。
- 尊重拒绝、边界和双方自主选择，不提供操控、纠缠或试探底线的策略。
- 优先轻改用户草稿，不把所有人改成同一种“标准话术”。

## 第一版范围

三个主要入口：

1. 我想认识她/他
2. 我想进一步了解她/他
3. 我遇到了具体困难

第一版计划包含背景输入、偏好与边界档案、下一步行动建议、表达辅助、证据说明、编辑反馈和互动回顾。

暂不包含自动发送、后台监听、成功率预测、自动订位，以及未经授权的真实聊天训练。

## 推荐开发顺序

1. 用虚构案例补齐两类核心场景，以及邀请、见面准备、拒绝和回顾场景。
2. 根据案例迭代输入/输出 Schema，并实现跨字段与证据引用校验。
3. 做一个最小后端：接收结构化输入、调用模型、校验输出、有限重试。
4. 做一个最小界面：输入背景、展示建议与依据、允许修改和反馈。
5. 用独立测试集对照基础提示词，记录失败案例后再决定技术栈与模型。
